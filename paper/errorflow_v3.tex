\begin{abstract}
Large language model fact verifiers can benefit from a second inference pass,
but applying correction prompts uniformly increases compute and may regress
already-correct predictions. We introduce ERRORFlow, a training-free residual
correction framework that stores source-domain action outcomes in a
non-parametric error memory and selectively invokes a frozen corrective prompt
when similar residual patterns indicate positive utility. ERRORFlow updates no
model weights and explicitly measures the quality--cost trade-off. Using
Qwen3-4B-Instruct-2507, train-selected conservative grouped development on
AVeriTeC shows that the revised no-label-filter router (R6-NLF) improves
accuracy by 1.83 points and macro-F1 by 2.05 points while routing 12.22\% of
examples. It also reduces harmful corrections relative to the historical
hard-label router. Frozen external evaluation improves B1 macro-F1 by 3.09
points on CLIMATE-FEVER, 3.55 points on SciFact oracle evidence, and 2.97
points on SciFact BM25 evidence; paired bootstrap intervals are positive,
although the BM25 accuracy interval crosses zero. Same-budget comparisons do
not establish universal superiority over HardLabel or confidence-only routing.
Component ablations show that the compatibility rule and neighborhood size
materially affect the quality--cost frontier, while no single similarity
metric is uniformly superior. Conflicting-evidence classification remains weak.
\keywords{Fact verification \and Training-free inference \and Error memory
\and Selective routing \and Retrieval-augmented verification}
\end{abstract}

\section{Introduction}

Fact verification systems must jointly reason over a claim and imperfect
evidence while deciding among support, refutation, insufficient evidence, and
in some datasets conflicting evidence. A second-pass critique can repair some
first-pass errors, but applying it to every example doubles label-scoring work
and can change correct predictions into incorrect ones. The central question
is therefore not only which corrective prompt to use, but when its expected
benefit justifies its cost.

We study this question without updating model parameters. ERRORFlow first
executes a frozen verifier, then retrieves residual outcomes from a
versioned source memory. A selective router invokes one frozen correction
action only when neighboring source outcomes indicate positive utility. The
method records helpful and harmful changes, route rate, and model forward
passes, enabling matched-budget comparisons against confidence, similarity,
label-conditional, static, and random routers.

Our experiments emphasize claim boundaries and reproducibility. Source-domain
evaluation excludes the complete query fold from memory and includes
near-duplicate grouping sensitivity. External target labels are not used for
routing or model selection. We evaluate an ontology-aligned four-label setting
on CLIMATE-FEVER, an adapter-sensitive oracle-rationale setting on SciFact,
and an open-corpus BM25 SciFact condition that exposes retrieval failures.

The main contributions are:
\begin{itemize}
  \item a source-supervised, parameter-frozen router that retrieves observed
  helpful and harmful outcomes of a fixed corrective action and applies that
  action only when local signed utility is positive;
  \item a reproducible residual-correction pipeline with immutable prompts,
  versioned outcome memory, deterministic routing, and explicit compute
  accounting;
  \item leakage-audited source evaluation with exact policy replay and
  near-duplicate-group sensitivity;
  \item matched-budget controls that separate corrective-action quality from
  routing quality; and
  \item cross-domain and retrieved-evidence analyses that identify both
  transfer gains and failure modes.
\end{itemize}

\section{Related Work}

\paragraph{Evidence-grounded fact verification.}
FEVER established large-scale claim verification over Wikipedia
\cite{thorne2018fever}; subsequent benchmarks test scientific claims
\cite{wadden2020scifact}, climate claims \cite{diggelmann2020climate},
multi-hop evidence \cite{jiang2020hover}, and real-world web evidence
\cite{schlichtkrull2024averitec}. Robustness work demonstrates that verifiers
can exploit evidence artifacts \cite{schuster2021vitaminc}, while structured
systems target faithful entailment \cite{krishna2022proofver}. Direct
leaderboard comparison is inappropriate when evidence, labels, training, or
metrics differ.

\paragraph{Test-time self-correction.}
Iterative critique can improve model outputs
\cite{madaan2023selfrefine,gao2023rarr,dhuliawala2024coverification}, but
intrinsic self-correction can fail without reliable feedback
\cite{huang2024cannot}. Self-Refine repeatedly feeds model-generated feedback
back to the same model; RARR retrieves sources and revises generated text; and
Chain-of-Verification plans and answers verification questions. ERRORFlow does
not generate a critique chain or revise free text: it exposes one alternative
frozen label-scoring instruction and learns only whether invoking that action
was helpful in similar source cases.

\paragraph{Selective inference and routing.}
Selective QA studies abstention under domain shift, while active and adaptive
retrieval allocate retrieval effort conditionally
\cite{kamath2020selective,jiang2023active,jeong2024adaptiverag,asai2024selfrag}.
These approaches motivate uncertainty and confidence controls. ERRORFlow's
router instead estimates the signed downstream value of a particular action,
including regressions, and compares it with confidence, margin,
label-conditional, similarity-only, static-pattern, and random routing at the
same realized route count.

\paragraph{Outcome-based non-parametric memory.}
Retrieval augmentation \cite{lewis2020rag}, case-based reasoning
\cite{das2021case}, and verbal memory \cite{shinn2023reflexion} motivate
non-parametric reuse. Their memories store knowledge, solutions, or verbal
experience. ERRORFlow stores action outcomes: observable B1 features, whether
A3 recovered an error or regressed a correct prediction, and action cost.
Cross-domain retrieval \cite{thakur2021beir}, long contexts
\cite{liu2024lost}, and noisy evidence \cite{fang2024noise} expose robustness
limits that motivate our retrieval-stratified analysis. The memory is
supervised by source labels and is training-free in parameters, not label-free.

\section{Problem Formulation}

Let a frozen verifier $f_{B1}$ map claim--evidence input $x=(c,E)$ to a
verdict, and let a fixed alternative instruction $f_{A3}$ be available at an
additional cost. A routing policy $\pi(x)\in\{0,1\}$ returns B1 when
$\pi(x)=0$ and A3 when $\pi(x)=1$. For a labeled source population, a routed
example is helpful when B1 is wrong and A3 is correct, harmful when B1 is
correct and A3 is wrong, and neutral otherwise. ERRORFlow estimates this
signed residual outcome from compatible source cases while constraining the
expected extra forward passes. The goal is not to learn a new verifier or a
new correction strategy, but to perform \emph{memory-guided selection of one
fixed corrective action}.

Target labels never enter $\pi$. They are read only after predictions are
materialized for evaluation. Source labels are required to construct outcome
memory, so ``training-free'' means no parameter optimization, not no
supervision.

\section{Methodology}

\subsection{Frozen Base Verifier}

Given claim $c$, evidence set $E$, and label set $\mathcal{Y}$, B1 computes the
mean token log probability of each candidate label under a fixed instruction:
\begin{equation}
s_y = \frac{1}{|y|}\sum_{t=1}^{|y|}\log p(y_t\mid c,E,y_{<t}).
\end{equation}
The predicted label is $\hat{y}=\arg\max_y s_y$. Four model forward passes are
used for four-label datasets. We use Qwen3-4B-Instruct-2507 with deterministic
label scoring and seed 2026.

\subsection{Corrective Action}

A3 is a second immutable instruction, \texttt{conflicting\_rescue\_v1}, that
asks the same model to reconsider evidence coverage, polarity, and potential
conflict. A3 uses the same candidate-label scoring rule as B1. Always-on A3
therefore adds four model forward passes per example.

Crucially, A3 does not receive B1's prediction, confidence, explanation, or
retrieved memories. It receives the same claim and evidence under a different
instruction and is therefore an alternative second-pass verifier, not a
conversational edit of B1. Table~\ref{tab:b1a3} isolates the intervention.

\subsection{Residual Outcome Memory}

Each source-memory record contains the source claim, B1 prediction and score
profile, evidence-length features, the A3 outcome, and observed utility. No
target label enters a route decision. For source evaluation, records from the
query's complete grouped fold are excluded. For external evaluation, the
complete frozen AVeriTeC train memory is used.

For query $q$ and memory record $i$, retrieval similarity is
\begin{equation}
S(q,i)=0.35J(T_q,T_i)+0.50\left(1-\tfrac12\lVert p_q-p_i\rVert_1\right)
+0.15\left(1+|e_q-e_i|/100\right)^{-1},
\end{equation}
where $J$ is set-token Jaccard similarity, $p$ a softmax-normalized B1 score
vector, and $e$ the whitespace evidence-token count. Records must match the
action, but the final R6-NLF policy does not require the memory record's B1
verdict to equal the query's B1 verdict. The complete score profile remains a
similarity feature, allowing cross-label outcomes to contribute when their
other residual signals are close. Let $w_i=S(q,i)$, and let $r_i$, $g_i$, and $c_i$
denote recovery, regression, and normalized cost. With $W=\sum_iw_i$,
\begin{equation}
\widehat R=\frac{\sum_iw_ir_i+1}{W+2},\quad
\widehat G=\frac{\sum_iw_ig_i+1}{W+2},\quad
\widehat C=\frac{\sum_iw_ic_i}{W},
\end{equation}
and utility is $U=\widehat R-\widehat G-0.1\widehat C$. R6-NLF retrieves five
records, requires at least two, and routes iff $U>0$. The historical
R6-HardLabel comparator applies the additional exact-B1-label filter.
With one constant-cost action, this penalty cannot change ordering at a fixed
budget; our experiments therefore validate residual outcome-memory routing,
not an independent heterogeneous-cost mechanism.

\subsection{Utility Estimation and Decision Boundary}

The additive one in each outcome numerator and additive two in the denominator
are symmetric Laplace-style smoothing. They pull sparse neighborhoods toward
equal recovery and regression rates. Because the effective sample size is
$W=\sum_iw_i$ rather than a count, this is a heuristic similarity-weighted
estimator, not a calibrated Bayesian posterior. Similarities are bounded but
are not renormalized before the sums; division by $W$ normalizes only the cost
average. If fewer than two records remain after action, ID, and fold filters,
R6-NLF does not route. Recovery means B1 wrong/A3 correct under
the offline source gold label; regression means B1 correct/A3 wrong.

Symmetric smoothing has a specific consequence for routing. The two
pseudo-counts cancel in the signed outcome term:
\begin{equation}
\widehat R-\widehat G
=\frac{\sum_i w_i(r_i-g_i)}{W+2}.
\end{equation}
Thus smoothing does not introduce independent positive and negative evidence
into net utility; it shrinks the magnitude of observed signed outcomes toward
zero. This explains why the Group-C unsmoothed estimator produced identical
route decisions in the tested configuration: removing the denominator
shrinkage changed score magnitudes but not which utilities crossed the fixed
boundary. This equivalence is empirical for that configuration, not a general
guarantee once costs, thresholds, or actions differ.

The zero boundary follows the operational objective: spend the second pass
only when estimated recovery exceeds estimated regression plus cost. The cost
unit is one additional four-forward-pass A3 call, so $\widehat C=1$ in the
current single-action experiment and 0.1 is a fixed utility penalty selected
on source development. No probabilistic confidence interval surrounds $U$;
near-zero routes may therefore be unstable. Threshold and weight sensitivity
are limitations, and the primary evidence comes from matched-budget controls
rather than interpreting $U$ as calibrated probability.

For mechanics, suppose five neighbors have similarities
$(.80,.70,.60,.50,.40)$, recovery indicators $(1,1,0,0,0)$, regression
indicators $(0,0,0,1,0)$, and unit costs. Then $W=3.0$,
$\widehat R=(1.5+1)/5=.50$, $\widehat G=(.5+1)/5=.30$,
$\widehat C=1$, and $U=.10>0$, so A3 is invoked. This arithmetic example is
not an experimental result; the release script exports a genuine routed trace
from the server artifacts for the final qualitative case table.

\subsection{Controls and Cost}

We compare B1, A3-All, confidence-only, R6-HardLabel, and R6-NLF in every
renewed evaluation. Source ablations additionally include random, margin,
label-conditional, similarity-only, static-pattern, and outcome-memory routers.
Selective controls receive exactly the realized R6-NLF route count. Average model forward
passes equal $4+4r$, where $r$ is the route rate.

\subsection{External Four-Label Transfer}

On CLIMATE-FEVER, A3-All improves B1 by 3.06 accuracy points and 5.85 macro-F1
points. R6-NLF routes 19.02\% and improves B1 by 1.56 accuracy and 3.09
macro-F1 points; both paired bootstrap intervals are positive
(Table~\ref{tab:delta-ci}). At the same budget, its differences from HardLabel
and confidence-only are inconclusive. NLF raises CONFLICTING F1 from 0.1111 to
0.1373, but this class remains weak; most absolute performance still comes
from SUPPORTED.

\subsection{SciFact Ontology Sensitivity}

With oracle rationales, projected R6-NLF improves accuracy by 2.33 points and
macro-F1 by 3.55 points, with positive paired bootstrap intervals
(Table~\ref{tab:delta-ci}); the exact accuracy McNemar test is weaker
($p=.065$). NLF and HardLabel have identical natural accuracy and no confirmed
paired difference. The raw four-label comparison is null. Moreover, A3
produces 96 CONFLICTING outputs under oracle evidence, and projection converts
90 additional examples to correct predictions. This result is therefore
adapter-mediated and cannot support projection-independent transfer.

\subsection{Retrieved-Evidence Robustness}

With open BM25 evidence, R6-NLF improves B1 macro-F1 by 2.97 points with a
positive bootstrap interval, while its 2.00-point accuracy interval crosses
zero. At the NLF budget, NLF is 1.00 accuracy and 1.03 macro-F1 points above
HardLabel, but the small-sample paired tests do not confirm superiority.
Only five A3 predictions are
projected, so this condition is not driven by mass ontology conversion.

The earlier retrieval-stratum audit used HardLabel. On 121 verifiable hits it
had net zero correctness change; on 67 misses it preserved B1 while A3-All
lost six net correct predictions; on 112 NEI claims it gained five. The new
NLF aggregate gains are consistent with selective harm avoidance, but a fresh
NLF stratum analysis was not used for model selection and is not inferred.

\subsection{Cross-Domain Summary}

Table~\ref{tab:delta-ci} summarizes frozen R6-NLF change over B1. Macro-F1
intervals are positive in all four protocols, but interpretation differs:
AVeriTeC is train-selected; SciFact oracle is projection-sensitive;
CLIMATE-FEVER has supplied candidates rather than open retrieval; and SciFact
BM25 accuracy is statistically inconclusive. Direct NLF--HardLabel and
NLF--confidence comparisons are mostly inconclusive, so the evidence supports
NLF as a competitive transferred router rather than a universally superior one.

\paragraph{Outcome memory matters.}
Destroying the association between retrieval features and observed outcomes
(NA3) reduces mean accuracy and macro-F1 relative to NA0. At seed 2026, NA0

information beyond memory access alone.

\paragraph{Instance-level versus class-level memory.}
NA0 exceeds the class-conditional estimator NA5 by 0.52 accuracy and 2.13
macro-F1 points. The Holm-adjusted correctness test is null ($p=.609$), while

class-balance benefit without establishing a corrected accuracy advantage.
The historical B5 and B15 implementations call the same
class-conditional estimator used by NA5 and produce identical outputs; B5 is therefore
retained only in the artifact.

\paragraph{Regression-aware utility.}
Removing the regression term (NA6) lowers matched-budget accuracy by 0.07 and
macro-F1 by 0.35 points relative to NA0; neither paired difference is
established. More importantly, NA6's natural $U>0$ rule routes all 3,068
claims, yielding 192 helpful but 205 harmful changes (net $-13$), whereas NA0
routes 375 with net $+56$. The experiment supports regression modeling as a
mechanism for selective abstention, but does not establish a fixed-budget
quality advantage.

The remaining extreme controls reinforce the same boundary. The global prior
(NA4) and correct-only memory (NA8) do not route naturally; forcing each to the
375-example budget produces net changes of $-14$ and $-4$. NA0 exceeds both
with positive paired accuracy and macro-F1 intervals after the declared
multiple-comparison protocol. Error-only memory (NA7), by contrast, is a
competitive reduced control: its matched differences from NA0 are
inconclusive, motivating the budget analysis below rather than a claim of
uniform dominance.

\subsection{What the Evidence Supports}

Outcome memory is useful because it estimates both recovery and regression of
the same fixed A3 action in nearby source cases. This differs from uncertainty
routing, which ranks ambiguity without observing whether A3 historically
helped that type of input. The matched-budget evidence supports improvement
over B1, random, confidence-only, and similarity-only routing on source
development. On external settings, NLF is not significantly better than
matched confidence or HardLabel; its transfer evidence is primarily the
paired improvement over B1. It does not establish a secure macro-F1 advantage
over label-conditional routing after Holm correction, and constant action cost
makes R6 equivalent to outcome-only memory ranking at a fixed budget.
Accordingly, ERRORFlow is described as
memory-guided selection of a fixed corrective action, not as learning reusable
correction strategies or heterogeneous cost-aware planning.

The memory ablations sharpen this interpretation. Shuffling outcomes degrades
both metrics and is rejected by the multiplicity-corrected correctness test,
showing that the feature--outcome association contains routing information.
However, recovery-only utility is statistically indistinguishable from NA0 at
375 routes, and error-only memory is stronger at low budgets. Harmful outcomes
therefore help define selective coverage and the higher-budget frontier, but
their inclusion is not uniformly beneficial at every operating point.

The historical hard-label ablations do not establish that every similarity component is
individually necessary or that manually assigned weights outperform uniform
weighting. In particular, removing claim similarity has negligible effect,
and both label-score removal and uniform weighting improve macro-F1 slightly.
These negative results are retained because ablation inclusion is based on
mechanistic relevance and statistical reliability rather than whether a row
favors the historical R6-HardLabel reference.

\section{Reproducibility and Audit}

All inference uses one frozen Qwen3-4B-Instruct-2507 identifier, BF16 on CUDA,
deterministic mean label log probability, and seed 2026. B1 and A3 instruction
SHA-256 values are \texttt{700ebdc1...decf7} and
\texttt{09e187ec...aaf}. These identify instruction strings; the reported
model hash identifies the model name, not weight files. Exact replay found
zero route and prediction mismatches, and rotating target gold labels did not
alter routes. Group exclusion removes the validation fold from usable memory;
it does not prove absence of shared evidence or semantic paraphrases. Large
experimental JSONL files remain server-side and are represented by an
artifact ledger rather than committed to Git.

The frozen NLF evaluation manifests have configuration IDs
\texttt{bdac31d1...5625b} for grouped AVeriTeC and
\texttt{19542dc4...b523} for each external protocol; input hashes in each
manifest distinguish the external datasets despite the shared policy ID.

\section{Limitations}

The experiments use one base-model checkpoint. Source results are
train-selected, and source memory uses labeled outcomes; training-free denotes
the absence of weight updates, not the absence of supervision. SciFact oracle
results depend strongly on label projection. CLIMATE-FEVER uses official
retrieved candidates rather than ERRORFlow retrieval, while the open SciFact
retriever is only a lexical baseline. Several external matched-router
comparisons remain statistically inconclusive. Finally, CONFLICTING-class
performance is weak, and constant action cost prevents an independent test of
heterogeneous cost-aware ranking. The hand-set similarity weights are not
validated as optimal, component signals may be redundant, and the Group-C
development harness used a slightly different token boundary from the
canonical memory implementation. We report both rather than treating their
route counts as interchangeable.

\paragraph{Ethics and broader impact.}
Selective correction can reduce unnecessary computation, but automated
verdicts should not replace human fact-checking. Memory may encode source
annotation choices and transfer them unevenly. Deployment should expose
evidence, abstain under unsupported retrieval, and monitor topic-specific
regressions. AVeriTeC is CC BY-NC 4.0; CLIMATE-FEVER is not redistributed by
this repository because its official repository declares no license.

\section{Conclusion}

ERRORFlow shows that a frozen corrective action can be invoked selectively
using non-parametric source residual outcomes. Development ablations select
R6-NLF, which admits cross-label neighbors while retaining the fixed action,
similarity function, and signed utility rule. The method reduces second-pass
compute and can improve a frozen verifier, but its strongest defensible effect
is selective harm avoidance under imperfect evidence. Frozen external reruns
show positive macro-F1 intervals over B1 under supplied candidates, oracle
rationales, and open BM25 evidence, but do not establish universal superiority
over simpler matched-budget routers; ontology adaptation must be reported
explicitly.

\section{Prompt and Scoring Details}
The rendered prompt is plain text, not a chat template. Evidence order is
preserved and only evidence text is included. Each candidate is tokenized as a
leading space plus the literal label. Candidate-token log probabilities are
averaged; four candidates require four independent forward passes. Exact ties
follow label order: SUPPORTED, REFUTED, NOT ENOUGH INFO, CONFLICTING. Reported
confidence is a softmax over mean label scores, not a calibrated sequence
probability. Although A3 asks to list evidence directions, label scoring does
not generate a rationale.

\paragraph{B1 instruction (SHA-256 \texttt{700ebdc1...decf7}).}
\begin{quote}\small
Audit whether the evidence contains credible support and credible
contradiction for the same essential claim. Choose CONFLICTING only when both
directions are genuinely present or the claim cherry-picks a mixed record. If
evidence supports one direction without a credible opposite, choose SUPPORTED
or REFUTED. If neither direction is established, choose NOT ENOUGH INFO.
\end{quote}

\paragraph{A3 instruction (SHA-256 \texttt{09e187ec...aaf}).}
\begin{quote}\small
Independently list the strongest supporting evidence and the strongest
refuting evidence for the same essential claim. Choose CONFLICTING only if
both directions are credible and materially established, including genuine
cherry-picking. Multiple sources alone are not a conflict. If only one
direction is established choose SUPPORTED or REFUTED; otherwise choose NOT
ENOUGH INFO.
\end{quote}

The phrase ``list'' is part of the immutable instruction, but the deployed
label-scoring decoder does not generate that list. It scores only the four
candidate verdict strings. A3 changes verification emphasis, not output format.

therefore reported as sensitivity rather than a same-budget win.
