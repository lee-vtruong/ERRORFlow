\begin{abstract}
Applying a second verification prompt uniformly increases compute and can
regress correct predictions. ERRORFlow stores source-domain outcomes of one
fixed alternative prompt and uses non-parametric memory to decide when to
escalate, without updating model weights. On grouped AVeriTeC development,
Qwen3-4B routing improves accuracy from 74.02\% to 75.85\% and macro-F1 from
54.60\% to 56.66\% while invoking the alternative prompt on 12.22\% of
examples. Frozen AVeriTeC-memory transfer yields smaller gains over Base:
+1.56 accuracy points on CLIMATE-FEVER, +2.33 on projected SciFact oracle,
and +2.00 on projected SciFact BM25; the BM25 accuracy interval includes
zero. In-domain cross-fitting raises the CLIMATE-FEVER gain to +2.28 points,
but native-three-label SciFact memory does not improve Base on train
cross-validation or frozen train-to-dev evaluation because Alt itself has
negative net utility. Thus source-memory mismatch is only a partial,
dataset-dependent explanation. Cross-fitted logistic and
boosted controls are competitive in source accuracy, while paired intervals
favor outcome memory in macro-F1; matched controls do not confirm a universal
advantage for global-neighbor compatibility or regression-aware ranking. An
independent Mistral-7B replication supports selective escalation but favors
same-label memory, so compatibility is treated as a backbone-dependent
operating choice rather than a fixed discovery.
\keywords{Fact verification \and Non-parametric routing \and Outcome memory
\and Selective routing \and Retrieval-augmented verification}
\end{abstract}

\section{Introduction}

Fact verification systems must jointly reason over a claim and imperfect
evidence while deciding among support, refutation, insufficient evidence, and
in some datasets conflicting evidence. A second-pass critique can repair some
first-pass errors, but applying it to every example doubles label-scoring work
and can change correct predictions into incorrect ones. The central question
is therefore not only which corrective prompt to use, but when its expected
benefit justifies its cost.

We study this question without updating model parameters. ERRORFlow first
executes a frozen verifier, then retrieves residual outcomes from a
versioned source memory. A selective router invokes one frozen correction
action only when neighboring source outcomes indicate positive utility. The
method records helpful and harmful changes, route rate, and model forward
passes, enabling matched-budget comparisons against confidence, similarity,
label-conditional, static, and random routers.

Our experiments emphasize claim boundaries and reproducibility. Source-domain
evaluation excludes the complete query fold from memory and includes
near-duplicate grouping sensitivity. External target labels are not used for
routing or model selection. We evaluate an ontology-aligned four-label setting
on CLIMATE-FEVER, an adapter-sensitive oracle-rationale setting on SciFact,
and an open-corpus BM25 SciFact condition that exposes retrieval failures.

The main contributions are:
\begin{itemize}
  \item an outcome-memory formulation for selecting whether to keep a base
  verdict or invoke one fixed alternative prompt, with no model-weight update;
  \item matched-budget evaluation against confidence, random, static, and
  supervised gates, with fold-safe memory exclusion and explicit forward-pass
  accounting; and
  \item cross-domain, retrieved-evidence, and second-backbone experiments that
  identify where selective escalation transfers and where compatibility and
  source utility fail to transfer.
\end{itemize}

\section{Related Work}

\paragraph{Evidence-grounded fact verification.}
FEVER established large-scale claim verification over Wikipedia
\cite{thorne2018fever}; subsequent benchmarks test scientific claims
\cite{wadden2020scifact}, climate claims \cite{diggelmann2020climate},
multi-hop evidence \cite{jiang2020hover}, and real-world web evidence
\cite{schlichtkrull2024averitec}. Robustness work demonstrates that verifiers
can exploit evidence artifacts \cite{schuster2021vitaminc}, while structured
systems target faithful entailment \cite{krishna2022proofver}. Direct
leaderboard comparison is inappropriate when evidence, labels, training, or
metrics differ.

\paragraph{Test-time self-correction.}
Iterative critique can improve model outputs
\cite{madaan2023selfrefine,gao2023rarr,dhuliawala2024coverification}, but
intrinsic self-correction can fail without reliable feedback
\cite{huang2024cannot}. Self-Refine repeatedly feeds model-generated feedback
back to the same model; RARR retrieves sources and revises generated text; and
Chain-of-Verification plans and answers verification questions. ERRORFlow does
not generate a critique chain or revise free text: it exposes one alternative
frozen label-scoring instruction and learns only whether invoking that action
was helpful in similar source cases.

\paragraph{Selective inference and routing.}
Selective QA studies abstention under domain shift, while active and adaptive
retrieval allocate retrieval effort conditionally
\cite{kamath2020selective,jiang2023active,jeong2024adaptiverag,asai2024selfrag}.
These approaches motivate uncertainty and confidence controls. LLM cascades
and routers allocate requests across models to trade response quality for cost
\cite{chen2024frugalgpt,ding2024hybrid,ong2025routellm}. Learning-to-defer
formulates a related decision between a predictor and a downstream expert
\cite{madras2018defer,mozannar2020defer}. ERRORFlow differs in that both
choices are immutable prompts of the same verifier, but its supervised source
problem is structurally close to predicting which action will be correct.
Accordingly, we compare non-parametric memory with a cross-fitted logistic
gate rather than presenting kNN as the only solution.

\paragraph{Incremental-action modeling.}
Uplift modeling estimates the incremental effect of an intervention and
distinguishes beneficial from harmful treatment cases
\cite{gutierrez2017uplift}. Our helpful/harmful/neutral labels are analogous
to positive, negative, and zero observed prompt effects because both Base and Alt
are cached for each labeled source example. This analogy is descriptive, not
a causal identification claim: prompts are not randomized treatments, and our
router predicts an observed paired action contrast.

\paragraph{Outcome-based non-parametric memory.}
Retrieval augmentation \cite{lewis2020rag}, case-based reasoning
\cite{das2021case}, and verbal memory \cite{shinn2023reflexion} motivate
non-parametric reuse. Their memories store knowledge, solutions, or verbal
experience. ERRORFlow stores action outcomes: observable Base features, whether
Alt recovered an error or regressed a correct prediction, and action cost.
Cross-domain retrieval \cite{thakur2021beir}, long contexts
\cite{liu2024lost}, and noisy evidence \cite{fang2024noise} expose robustness
limits that motivate our retrieval-stratified analysis. The memory is
supervised by source labels and is training-free in parameters, not label-free.

\section{Problem Formulation}

Let a frozen verifier $f_{Base}$ map claim--evidence input $x=(c,E)$ to a
verdict, and let a fixed alternative instruction $f_{Alt}$ be available at an
additional cost. A routing policy $\pi(x)\in\{0,1\}$ returns Base when
$\pi(x)=0$ and Alt when $\pi(x)=1$. For a labeled source population, a routed
example is helpful when Base is wrong and Alt is correct, harmful when Base is
correct and Alt is wrong, and neutral otherwise. ERRORFlow estimates this
signed residual outcome from compatible source cases while constraining the
expected extra forward passes. The goal is not to learn a new verifier or a
new correction strategy, but to perform \emph{memory-guided selection of one
fixed corrective action}.

Target labels never enter $\pi$. They are read only after predictions are
materialized for evaluation. Source labels are required to construct outcome
memory, so ``training-free'' means no parameter optimization, not no
supervision.

\section{Methodology}

\subsection{Frozen Base Verifier}

Given claim $c$, evidence set $E$, and label set $\mathcal{Y}$, Base computes the
mean token log probability of each candidate label under a fixed instruction:
\begin{equation}
s_y = \frac{1}{|y|}\sum_{t=1}^{|y|}\log p(y_t\mid c,E,y_{<t}).
\end{equation}
The predicted label is $\hat{y}=\arg\max_y s_y$. Four model forward passes are
used for four-label datasets. We use Qwen3-4B-Instruct-2507 with deterministic
label scoring and seed 2026.

\subsection{Corrective Action}

Alt is a second immutable instruction, \texttt{conflicting\_rescue\_v1}, that
asks the same model to reconsider evidence coverage, polarity, and potential
conflict. Alt uses the same candidate-label scoring rule as Base. Always-on Alt
therefore adds four model forward passes per example.

Crucially, Alt does not receive Base's prediction, confidence, explanation, or
retrieved memories. It receives the same claim and evidence under a different
instruction and is therefore an alternative second-pass verifier, not a
conversational edit of Base. Table~\ref{tab:b1a3} isolates the intervention.

\subsection{Residual Outcome Memory}

Each source-memory record contains the source claim, Base prediction and score
profile, evidence-length features, the Alt outcome, and observed utility. No
target label enters a route decision. For source evaluation, records from the
query's complete grouped fold are excluded. For external evaluation, the
complete frozen AVeriTeC train memory is used.

For query $q$ and memory record $i$, retrieval similarity is
\begin{equation}
S(q,i)=0.35J(T_q,T_i)+0.50\left(1-\tfrac12\lVert p_q-p_i\rVert_1\right)
+0.15\left(1+|e_q-e_i|/100\right)^{-1},
\end{equation}
where $J$ is set-token Jaccard similarity, $p$ a softmax-normalized Base score
vector, and $e$ the whitespace evidence-token count. Records must match the
action, but the final Memory-Global policy does not require the memory record's Base
verdict to equal the query's Base verdict. The complete score profile remains a
similarity feature, allowing cross-label outcomes to contribute when their
other residual signals are close. Let $w_i=S(q,i)$, and let $r_i$, $g_i$, and $c_i$
denote recovery, regression, and normalized cost. With $W=\sum_iw_i$,
\begin{equation}
\widehat R=\frac{\sum_iw_ir_i+1}{W+2},\quad
\widehat G=\frac{\sum_iw_ig_i+1}{W+2},\quad
\widehat C=\frac{\sum_iw_ic_i}{W},
\end{equation}
and utility is $U=\widehat R-\widehat G-0.1\widehat C$. The global-neighbor
variant retrieves five records, requires at least two, and routes iff $U>0$.
The same-label comparator additionally requires the memory record's Base verdict
to match the query's Base verdict. With one constant-cost action,
$\widehat C=1$ whenever a route is eligible, so the cost term is exactly a
threshold shift. It cannot change ranking at a fixed budget. We therefore test
outcome-memory prompt escalation, not general cost-aware planning.

\subsection{Utility Estimation and Decision Boundary}

The additive one in each outcome numerator and additive two in the denominator
are symmetric Laplace-style smoothing. They pull sparse neighborhoods toward
equal recovery and regression rates. Because the effective sample size is
$W=\sum_iw_i$ rather than a count, this is a heuristic similarity-weighted
estimator, not a calibrated Bayesian posterior. Similarities are bounded but
are not renormalized before the sums; division by $W$ normalizes only the cost
average. If fewer than two records remain after action, ID, and fold filters,
Memory-Global does not route. Recovery means Base wrong/Alt correct under
the offline source gold label; regression means Base correct/Alt wrong.

Symmetric smoothing has a specific consequence for routing. The two
pseudo-counts cancel in the signed outcome term:
\begin{equation}
\widehat R-\widehat G
=\frac{\sum_i w_i(r_i-g_i)}{W+2}.
\end{equation}
Thus smoothing does not introduce independent positive and negative evidence
into net utility; it shrinks the magnitude of observed signed outcomes toward
zero. This explains why the unsmoothed ablation produced identical
route decisions in the tested configuration: removing the denominator
shrinkage changed score magnitudes but not which utilities crossed the fixed
boundary. This equivalence is empirical for that configuration, not a general
guarantee once costs, thresholds, or actions differ.

The zero boundary is one source-selected operating point. Because cost is
constant, changing its coefficient is equivalent to changing this boundary.
Recovery-only matches the full ranking at several low budgets, so the present
experiments do not isolate regression subtraction as a universally superior
ranking rule. Its clearest role is controlling natural coverage: without the
subtraction, the smoothed recovery estimate is positive for every query and
the zero-threshold policy escalates all examples. We rely on matched-budget
controls rather than interpreting $U$ as calibrated probability.

For mechanics, suppose five neighbors have similarities
$(.80,.70,.60,.50,.40)$, recovery indicators $(1,1,0,0,0)$, regression
indicators $(0,0,0,1,0)$, and unit costs. Then $W=3.0$,
$\widehat R=(1.5+1)/5=.50$, $\widehat G=(.5+1)/5=.30$,
$\widehat C=1$, and $U=.10>0$, so the alternative prompt is invoked. This
arithmetic example is not an experimental result. Two genuine routed cases,
exported under fold-safe memory exclusion, appear in
Appendix~\ref{sec:worked-cases}.

\subsection{Controls and Cost}

We compare the base prompt, always-on alternative prompt, confidence-only,
same-label memory, and global-neighbor memory in every renewed evaluation.
Source ablations additionally include random, margin, label-conditional,
similarity-only, static-pattern, and a cross-fitted logistic gate trained on
the same pre-action features.
Selective controls receive exactly the realized Memory-Global route count. Average model forward
passes equal $4+4r$, where $r$ is the route rate.

The SciFact retriever ranks all 5,183 corpus documents with BM25 over title and

therefore not treated as an untouched holdout. Any additional evaluation on
those 500 claims is labeled post-selection regression evidence rather than a
confirmatory estimate. The external datasets above remain the frozen transfer
tests used in this paper.

We report accuracy, macro-F1, per-class F1, helpful and harmful prediction
changes, route rate, and average forward passes. Paired comparisons use exact
two-sided McNemar tests and 5,000-sample paired bootstrap confidence intervals.
Source matched-router comparisons additionally apply Holm correction.

\subsection{Source-Domain Routing}

Under conservative token-Jaccard 0.90 grouping, the development-selected
Memory-Global policy improves AVeriTeC accuracy by 1.83 points and macro-F1 by 2.05
points while routing 12.22\%. It produces 94 helpful and 38 harmful changes
(net $+56$), compared with 90/44 (net $+46$) for Memory-SameLabel at 11.18\%
routing. At the Memory-Global budget, Memory-Global exceeds confidence-only by 1.79 accuracy and
1.52 macro-F1 points; both paired intervals are positive. Compared with
Memory-SameLabel at the same budget, the differences are +0.23 and +0.43 points and
both intervals cross zero. These are source-development results, not an
independent generalization estimate.

A group-cross-fitted linear ensemble of the Base and Alt label scores is a
stronger simple baseline than either prompt alone: it reaches 75.62 accuracy
and 55.85 macro-F1.  Relative to Base, its accuracy gain is supported by an
exact McNemar test ($p=.0035$) and a paired 95\% interval of
$[+.0055,+.0261]$, whereas its macro-F1 interval crosses zero
($[-.0025,+.0277]$).  The ensemble nevertheless evaluates both prompts for
every claim (8.0 forward passes).  The global-neighbor memory router has
higher point estimates (75.85 accuracy and 56.66 macro-F1) while averaging
4.49 passes.  Direct pairing does not establish a quality difference:
ensemble-minus-router accuracy is $-.0023$ (95\% CI
$[-.0114,+.0062]$, exact McNemar $p=.671$), and macro-F1 is $-.0081$
(95\% CI $[-.0225,+.0058]$).  Thus the supported advantage is computational:
the router attains a statistically indistinguishable point on these metrics
without evaluating Alt for every claim.  Finally, an oracle that invokes Alt
exactly on the 192 helpful cases has 6.26 points of available accuracy gain.
The natural router's net gain of 56 therefore captures 29.17\% of that
helpful-correction headroom, leaving substantial room for better selection.

\subsection{External Four-Label Transfer}

On CLIMATE-FEVER, Alt-All improves Base by 3.06 accuracy points and 5.85 macro-F1
points. Global-neighbor memory routes 19.02\% and improves Base by 1.56 accuracy and 3.09
macro-F1 points; both paired bootstrap intervals are positive
(Table~\ref{tab:delta-ci}). At the same budget, its differences from same-label memory
and confidence-only are inconclusive. Memory-Global raises CONFLICTING F1 from 0.1111 to
0.1373, but this class remains weak; most absolute performance still comes
from SUPPORTED. The frozen source-selected score ensemble reaches the same
accuracy as Alt-All and 0.4329 macro-F1. It exceeds Memory-Global by 1.50
accuracy points (95\% CI $[+.0020,+.0280]$, exact McNemar $p=.0346$) and
2.12 macro-F1 points (95\% CI $[+.0029,+.0394]$), but evaluates both prompts
for every claim. A selective routed-score fusion variant does not improve
Memory-Global: its accuracy and macro-F1 are 0.5355 and 0.4068, and both
paired intervals include zero.

\subsection{SciFact Ontology Sensitivity}

With oracle rationales, projected Memory-Global improves accuracy by 2.33 points and
macro-F1 by 3.55 points, with positive paired bootstrap intervals
(Table~\ref{tab:delta-ci}); the exact accuracy McNemar test is weaker
($p=.065$). Memory-Global and Memory-SameLabel have identical natural accuracy and no confirmed
paired difference. The raw four-label comparison is null. Moreover, Alt
produces 96 CONFLICTING outputs under oracle evidence, and projection converts
90 additional examples to correct predictions. This result is therefore
adapter-mediated and cannot support projection-independent transfer.
Always-on policies are substantially stronger in this condition. Alt-All

evidence that source-memory conservatism leaves much of Alt's target-domain
benefit unused.

\subsection{Retrieved-Evidence Robustness}

With open BM25 evidence, Memory-Global improves Base macro-F1 by 2.97 points with a

Only five Alt predictions are
projected, so this condition is not driven by mass ontology conversion.

The earlier retrieval-stratum audit used Memory-SameLabel. On 121 verifiable hits it

Memory-Global stratum analysis was not used for model selection and is not inferred.

\subsection{Cross-Domain Summary}

Table~\ref{tab:delta-ci} summarizes frozen Memory-Global change over Base. Macro-F1
intervals are positive in all four protocols, but interpretation differs:
AVeriTeC is train-selected; SciFact oracle is projection-sensitive;
CLIMATE-FEVER has supplied candidates rather than open retrieval; and SciFact
BM25 accuracy is statistically inconclusive. Direct Memory-Global--Memory-SameLabel and
Memory-Global--confidence comparisons are mostly inconclusive, so the evidence supports
Memory-Global as a competitive transferred router rather than a universally superior one.

\subsection{What the Evidence Supports}

Table~\ref{tab:claims} separates the demonstrated result from open claims.
Outcome memory ranks the observed paired effect of the same fixed alternative
prompt, whereas confidence ranks ambiguity without observing whether that
prompt helped similar source examples. The cross-fitted logistic result shows
that these source labels can also support a conventional supervised gate;
kNN contributes a direct case-based representation, not exclusive access to
the signal.

\midrule

On external settings, always-on Alt is stronger than the selective router. A
source-selected score ensemble also exceeds memory on CLIMATE-FEVER and has
the strongest SciFact-BM25 accuracy point estimate, while Alt-All remains
significantly stronger than the ensemble on SciFact oracle. Therefore, when
eight forwards per claim are acceptable, the current external results favor
always-on inference rather than ERRORFlow. The router's practical role is a
compute-constrained operating point: it retains part of the quality gain at
roughly 4.3--4.8 average forwards, not a quality-dominant replacement for
Alt-All. In-domain memory confirms this source-mismatch account on
CLIMATE-FEVER, but SciFact does not: under matched native-three-label prompts,
Alt is harmful on both train and dev, so the limiting factor is action quality
rather than memory provenance. Memory mismatch is therefore a
dataset-dependent diagnosis, not a general explanation of transfer.
Constant action cost makes the cost coefficient a threshold shift, and the
current evidence does not identify regression subtraction as a superior
fixed-budget ranking rule. Accordingly, ERRORFlow is described as
outcome-memory-guided selective prompt escalation, not reusable strategy
learning or general cost-aware planning.

The memory ablations sharpen this interpretation. Shuffling outcomes degrades
both metrics and is rejected by the multiplicity-corrected correctness test,
showing that the feature--outcome association contains routing information.
However, recovery-only utility is statistically indistinguishable from NA0 at
375 routes, and error-only memory is stronger at low budgets. Harmful outcomes
therefore help define selective coverage and the higher-budget frontier, but
their inclusion is not uniformly beneficial at every operating point.

The Memory-Global mechanism ablation further limits the interpretation. Cross-label-only
memory is harmful, while suppressing or shuffling cross-label outcomes does
not significantly reduce matched performance. The stricter NB8 control also
preserves Memory-Global's global support and abstention geometry while neutralizing
cross-label outcomes, yet remains statistically indistinguishable. The
current evidence therefore supports compatibility relaxation, global
candidate-pool competition, and selective pruning, not a causal claim that
instance-specific outcomes transferred across predicted labels are
individually necessary. This distinction is retained even though Memory-Global has the
strongest joint natural AVeriTeC point estimate under the main Qwen backbone.

The final-Memory-Global component tests establish a corrected accuracy contribution from
label-score similarity and a macro-F1 contribution from evidence length, but
do not establish an independent claim-Jaccard effect or superiority of manual
weights over uniform weights. Historical same-label removals differ---notably,
label-score removal had a much smaller effect---which confirms that conclusions
must not be transferred across candidate spaces. These negative results are
retained because ablation inclusion is based on mechanistic relevance and
statistical reliability rather than whether a row favors ERRORFlow.

\section{Limitations}

The main ablation suite uses one Qwen checkpoint; the Mistral replication
covers only grouped AVeriTeC and CLIMATE-FEVER and does not repeat every
component ablation or SciFact protocol. Source results are train-selected,
and source memory uses labeled outcomes; training-free denotes
the absence of weight updates, not the absence of supervision. SciFact oracle
results depend strongly on label projection. CLIMATE-FEVER uses official
retrieved candidates rather than ERRORFlow retrieval, while the open SciFact
retriever is only a lexical baseline. Several external matched-router
comparisons remain statistically inconclusive. Finally, CONFLICTING-class
performance is weak, and constant action cost prevents an independent test of
heterogeneous cost-aware ranking. The hand-set similarity weights are not
validated as optimal, component signals may be redundant, and the broad
Group-C development harness used a slightly different token boundary from the
canonical memory implementation. We report both rather than treating their
route counts as interchangeable. Source-memory subset sensitivity is post-hoc
and severely changes route rate; it cannot support target-specific memory
selection.

The in-domain analysis adds another protocol boundary. CLIMATE-FEVER has only
one labeled release, so its five-fold result is cross-fitted rather than an
untouched test. SciFact train$\rightarrow$dev excludes dev labels from memory
and routing, but the dev set had already been inspected elsewhere in this
project. Moreover, the native-three-label prompts produce markedly different
Base and Alt behavior from the historical four-label projection experiment.
The comparison diagnoses action and memory mismatch; it is not a clean
estimate of changing memory while holding every other protocol detail fixed.

The official AVeriTeC development labels were previously opened and cannot
serve as a new unbiased holdout. The global-neighbor choice and several
hyperparameters arose from a broad source-development search, so the grouped
gain is development evidence rather than a confirmatory estimate. A
predeclared run on hidden official evaluation data or another unopened
population is still required.

\paragraph{Ethics and broader impact.}
Selective correction can reduce unnecessary computation, but automated
verdicts should not replace human fact-checking. Memory may encode source
annotation choices and transfer them unevenly. Deployment should expose
evidence, abstain under unsupported retrieval, and monitor topic-specific
regressions. AVeriTeC is CC BY-NC 4.0; CLIMATE-FEVER is not redistributed by
this repository because its official repository declares no license.

\section{Conclusion}

ERRORFlow shows that a frozen alternative prompt can be invoked selectively
using non-parametric source action outcomes. The method reduces second-pass
compute and improves the base prompt in several studied protocols, but not
under native-three-label SciFact in-domain evaluation. Always-on correction
is stronger on the original external conditions and a supervised logistic
gate is competitive on source development. The evidence therefore supports
memory-based selective prompt escalation, not a uniquely optimal kNN router,
cross-label knowledge transfer, or general cost-aware planning. Compatibility
is a backbone-dependent operating choice: global neighbors give the strongest
Qwen development point estimate, whereas same-label memory is stronger for
Mistral. In-domain memory partially resolves CLIMATE-FEVER transfer but cannot
rescue a harmful SciFact alternative action. Future confirmation requires an
untouched held-out evaluation and a frozen predeclared configuration.

\section{Prompt and Scoring Details}
The rendered prompt is plain text, not a chat template. Evidence order is
preserved and only evidence text is included. Each candidate is tokenized as a
leading space plus the literal label. Candidate-token log probabilities are
averaged; four candidates require four independent forward passes. Exact ties
follow label order: SUPPORTED, REFUTED, NOT ENOUGH INFO, CONFLICTING. Reported
confidence is a softmax over mean label scores, not a calibrated sequence
probability. Although Alt asks to list evidence directions, label scoring does
not generate a rationale.

\paragraph{Base instruction (SHA-256 \texttt{700ebdc1...decf7}).}
\begin{quote}\small
Audit whether the evidence contains credible support and credible
contradiction for the same essential claim. Choose CONFLICTING only when both
directions are genuinely present or the claim cherry-picks a mixed record. If
evidence supports one direction without a credible opposite, choose SUPPORTED
or REFUTED. If neither direction is established, choose NOT ENOUGH INFO.
\end{quote}

\paragraph{Alt instruction (SHA-256 \texttt{09e187ec...aaf}).}
\begin{quote}\small
Independently list the strongest supporting evidence and the strongest
refuting evidence for the same essential claim. Choose CONFLICTING only if
both directions are credible and materially established, including genuine
cherry-picking. Multiple sources alone are not a conflict. If only one
direction is established choose SUPPORTED or REFUTED; otherwise choose NOT
ENOUGH INFO.
\end{quote}

The phrase ``list'' is part of the immutable instruction, but the deployed
label-scoring decoder does not generate that list. It scores only the four
candidate verdict strings. Alt changes verification emphasis, not output format.

\section{Statistical Detail and Negative Findings}
For grouped AVeriTeC, Memory-Global changes 94 errors to correct and 38 correct
predictions to errors (McNemar $p=1.19\times10^{-6}$). At the same 375-route
budget, Memory-Global versus Memory-SameLabel has $\Delta$accuracy $=.00228$ ($p=.324$) and
$\Delta$macro-F1 $=.00435$, with both intervals crossing zero; versus
confidence it has $\Delta$accuracy $=.01793$ ($p=5.29\times10^{-5}$) and
$\Delta$macro-F1 $=.01515$, with both intervals positive. Natural Memory-Global versus
Memory-SameLabel has a positive macro-F1 interval but inconclusive accuracy.

On CLIMATE-FEVER, Memory-Global versus Base has McNemar $p=.00791$, while its matched
comparisons with Memory-SameLabel and confidence are null. On SciFact oracle, the
bootstrap intervals over Base are positive but exact McNemar is $p=.0654$; all
direct matched-router comparisons are inconclusive. On SciFact BM25, Memory-Global's
macro-F1 interval over Base is positive while accuracy crosses zero; at the Memory-Global
budget its +.0100 accuracy difference over Memory-SameLabel has $p=.25$. The oracle
raw four-label Memory-SameLabel comparison remains null, so projected SciFact gains
must still be interpreted as adapter-mediated.

The in-domain experiment sharpens this negative finding. On grouped
CLIMATE-FEVER, Memory-Global improves Base by .0228 accuracy
(95\% CI [.0104,.0352], exact McNemar $p=.000562$) and .0335 macro-F1
(95\% CI [.0187,.0481]). In contrast, native-three-label SciFact shows no
accuracy improvement on oracle train cross-validation ($-.0025$), frozen
oracle train-to-dev evaluation (.0000), BM25 train cross-validation
($-.0049$), or frozen BM25 train-to-dev evaluation ($-.0100$); every paired
accuracy interval contains zero. This rules out a general claim that replacing
source memory with target-domain memory is sufficient to repair transfer.

NA7 is deliberately retained because it nearly matches NA0 at the primary

therefore reported as sensitivity rather than a same-budget win.
